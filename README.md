# lab2

Лабораторна робота №2 з об’єктно-орієнтованого програмування.
Консольний інтернет-магазин для конфігурації механічних клавіатур на Python.

## Запуск

Потрібен Python 3.10+.

```bash
python main.py
```

У Linux також можна використовувати `python3 main.py`.

## Можливості

- Перегляд каталогу товарів.
- Покрокова конфігурація клавіатури (Wizard).
- Перевірка сумісності компонентів.
- Рекомендації аксесуарів.
- Підрахунок вартості та застосування знижок.

## Патерни

- Factory Method - створення товарів (`lab2/factories.py`).
- Builder - складання клавіатури (`lab2/builder.py`).
- Strategy - розрахунок знижок (`lab2/discounts.py`).

Дані товарів і акцій містяться у `data/catalog.json`.
